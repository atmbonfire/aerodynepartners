# Aerodyne Partners Homepage — Version 1

This is a static, responsive homepage designed for GitHub Pages.

## Uploading to GitHub

1. Open your `aerodynepartners` repository.
2. Upload the contents of this folder to the repository root.
3. Confirm `index.html` is located at the top level of the repository.
4. Commit the files.
5. In **Settings → Pages**, deploy from the `main` branch and `/ (root)` folder.

## Files

- `index.html` — homepage content and structure
- `assets/css/style.css` — all visual styling and responsive layout
- `assets/js/main.js` — mobile navigation and automatic copyright year
- `assets/images/aerodyne-logo.jpg` — current approved logo artwork
- `assets/images/favicon.png` — browser-tab icon
